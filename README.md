# CareerBoard React — Fixed Version

A responsive React job application tracker for a junior developer portfolio.

## Run it

Open PowerShell in the folder that contains `package.json`, then run:

```powershell
npm install
npm run dev
```

Open the exact `Local:` address shown by Vite, normally:

```text
http://localhost:5173/
```

## Production check

```powershell
npm run build
npm run preview
```

## Included features

- Add, edit and delete job applications
- Wishlist, Applied, Interview, Offer and Rejected stages
- Search and filters
- Dashboard totals
- Follow-up dates
- Contact details and notes
- CSV export
- Local browser storage
- Responsive layout

## Important

Do not double-click `index.html`. Run the app through `npm run dev`.
